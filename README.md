# Twitch Chat Widget для OBS

- `index.html` — сайт-конфигуратор: настраиваете чат, видите превью, копируете ссылку
- `chat.html` — сам виджет, который вставляется в OBS

Сервер, база данных и токены Twitch не нужны: это два статических файла, чат читается анонимно.

## Как поставить на свой хост

Главное правило: **оба файла лежат в одной папке**. Конфигуратор строит ссылку на `chat.html` рядом с собой.

### Обычный хостинг (cPanel, ISPmanager, Beget, Timeweb, reg.ru и т.п.)
1. Откройте файловый менеджер в панели хостинга или подключитесь по FTP (FileZilla).
2. Зайдите в корень сайта (`public_html`, `www` или `htdocs`).
3. Создайте папку, например `chat`, и загрузите туда `index.html` и `chat.html`.
4. Откройте `https://ваш-сайт.ru/chat/`.

### Свой сервер (VPS) с nginx
```bash
sudo mkdir -p /var/www/chat
sudo cp index.html chat.html /var/www/chat/
```
Добавьте в блок `server { ... }` вашего сайта:
```nginx
location /chat/ {
    alias /var/www/chat/;
    index index.html;
}
```
```bash
sudo nginx -t && sudo systemctl reload nginx
```

### Бесплатно, без своего хоста
- **GitHub Pages**: новый репозиторий → загрузить оба файла → Settings → Pages → Branch: `main` → сайт появится по адресу `https://логин.github.io/репозиторий/`.
- **Netlify / Cloudflare Pages**: перетащите папку с файлами на страницу деплоя.

## Подключение в OBS

1. Откройте конфигуратор, впишите имя канала и настройте внешний вид.
2. Нажмите **«Копировать»**.
3. OBS → Источники → **+** → **Браузер** → вставьте ссылку в поле **URL**.
4. Ширину и высоту возьмите такие же, как в поле «Источник» в конфигураторе.

Фон прозрачный, свой CSS в OBS добавлять не нужно.

## Параметры chat.html (если хотите собрать ссылку вручную)

| Параметр | По умолчанию | Описание |
|---|---|---|
| `channel` | — | Имя канала (обязательно) |
| `font`, `size`, `weight` | Inter, 20, 500 | Шрифт из Google Fonts, размер, толщина |
| `color` | ffffff | Цвет текста (hex без `#`) |
| `shadow` | soft | `none` / `soft` / `stroke` |
| `emote` | 1.6 | Размер смайлов относительно текста |
| `namecolor` | — | Один цвет для всех ников |
| `badges`, `colon` | 1, 1 | Значки, двоеточие после ника |
| `layout` | inline | `inline` или `stack` (ник над текстом) |
| `bgc`, `bga`, `radius` | 000000, 45, 8 | Цвет подложки, непрозрачность 0–100, скругление |
| `fit` | 0 | Подложка по ширине текста |
| `accent` | 9147ff | Цвет оповещений о подписках и рейдах |
| `order`, `align` | down, left | Новые снизу/сверху (`up`), выравнивание `right` |
| `anim` | slide | `slide` / `side` / `fade` / `pop` / `none` |
| `gap`, `pad` | 6, 10 | Отступы между сообщениями и от краёв |
| `fade`, `max` | 0, 50 | Скрывать через N секунд, максимум сообщений |
| `emotes3p`, `notices`, `commands` | 1, 1, 0 | Смайлы 7TV/BTTV/FFZ, оповещения, `!команды` |
| `hide` | боты | Скрытые ники через запятую |
| `demo` | 0 | Тестовые сообщения |
| `server` | Twitch | Свой WebSocket-сервер чата, например ретранслятор на вашем хосте |

## Если чат не подключается

Виджет пишет причину в левом верхнем углу:
- **«Канал не найден»**: впишите имя из ссылки `twitch.tv/имя` латиницей, а не отображаемый ник.
- **«Не удаётся соединиться с сервером чата»**: соединение с `irc-ws.chat.twitch.tv` блокирует провайдер, антивирус, фаервол или VPN.
